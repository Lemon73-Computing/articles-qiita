## TL;DR

- Avalonia による .NET MAUI Backend により、Linux、Web で動かすことができるように (詳細は[姉妹記事]()にて)
- .NET Platform の maui-labs で、サポート外ではあるが .NET MAUI の Linux 対応を試験中 (詳細は[姉妹記事]()にて)
- 今までの主力だった maui-linux (MauiGtk Community) は事実上終了へ

## はじめに

.NET MAUI の Linux 対応について、今年 (2026年) 上半期は2つの大きなニュースがありました。Avalonia による .NET MAUI Backend の提供、Microsoft による半公式プロジェクト maui-labs の登場。

今まで「非現実的」であった .NET MAUI の Linux 対応は一気に現実的になっていきました。

一方、現在まで Linux 対応を目標として開発を続けてきた maui-linux、このプロジェクトはどうなったのでしょうか?歴史とともに振り返ってみましょう。
