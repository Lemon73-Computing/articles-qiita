## TL;DR

- Avalonia による .NET MAUI Backend により、Linux、Web で動かすことができるように
- .NET Platform の maui-labs で、サポート外ではあるが .NET MAUI の Linux 対応を試験中
- 今までの主力だった maui-linux (MauiGtk Community) は事実上終了へ (詳細は[姉妹記事]()にて)

## はじめに

2022年に正式リリースされた .NET MAUI[^maui-support]。Linux は発表当時からコミュニティーサポート[^community1][^community2]であり、Linux 上で動かすことは事実上[^virtually]不可能でした[^linux-vscode]。

[^maui-support]: https://devblogs.microsoft.com/dotnet/introducing-dotnet-maui-one-codebase-many-platforms/#:~:text=targeting%20Android%2C%20iOS%2C%20macOS%2C%20and%20Windows
[^community1]: https://forest.watch.impress.co.jp/img/wf/docs/1254/643/html/image5.jpg.html
[^community2]: https://github.com/dotnet/maui/discussions/71
[^virtually]: maui-linux のサンプルアプリケーションは部分的に動かすことができますが、Windows などで動く .NET MAUI と同じコードから生成することは (おそらく) 不可能なため"事実上"という言い回しをしています
[^linux-vscode]: .NET7 以降 (?)、開発環境として Linux を利用し、Android 向けに発行することはできます。が、ここでいう"動かす"は、Android などの仮想環境を使わずにネイティブで動かすことです

しかし今年 (2026年) 上半期、突如2つの大きなニュースが発表されました。**Avalonia による .NET MAUI Backend の公開** [^avalonia-2025-10][^avalonia-2025-11][^avalonia-2026-3] 、そして **.NET Platform による半公式プロジェクト maui-labs の登場** [^redth-github-maui-gtk][^redth-github-pr-to-maui-labs]。

[^avalonia-2025-10]: https://avaloniaui.net/blog/avalonia-maui-progress-update
[^avalonia-2025-11]: https://avaloniaui.net/blog/net-maui-is-coming-to-linux-and-the-browser-powered-by-avalonia
[^avalonia-2026-3]: https://avaloniaui.net/blog/maui-avalonia-preview-1
[^redth-github-maui-gtk]: https://github.com/Redth/Maui.Gtk
[^redth-github-pr-to-maui-labs]: https://github.com/dotnet/maui-labs/pull/29

これにより、.NET MAUI の Linux 向けビルドは一気に現実的となってきました。

本記事では、その背景と技術的な紹介を行います。

### 歴史

#### .NET MAUI vs Avalonia

まず、.NET MAUI と Avalonia の違いについて見てみましょう。

| フレームワーク | 初出 | 正式リリース |
| -- | -- | -- |
| (Xamarin) | 2011/5/16 (Xamarin 社設立) | 2013/2 (Xamarin 2.0) |
| .NET MAUI | 2020/5/19 (Microsoft Build 2020) | 2022/5/23 (.NET6) |
| Avalonia UI | 2013/12/5 (Perspex) | 2016/8 (v0.4.0) |

登場については、.NET MAUI は比較的最近のように思えますが、前身の Xamarin を含むとほぼ同時期です。

| フレームワーク | Windows | macOS | Linux | Android | iOS | 他 |
| -- | -- | -- | -- | -- | -- | -- |
| (Xamarin) | o | o | o (GTK#) | o | o | Tizen |
| .NET MAUI | o | o | x (コミュニティー) | o | o | Tizen, (Blazor Hybrid) |
| Avalonia UI | o | o | o | o | o | Wasm |

| フレームワーク | 開発元/サポート | メインターゲット[^main-target] | UI | 言語 |
| -- | -- | -- | -- | -- |
| (Xamarin) | Xamarin → Microsoft (+ コミュニティー) | モバイル端末 | ネイティブ | C# |
| .NET MAUI | Microsoft (+ .NET コミュニティー) | モバイル端末 | ネイティブ | C# |
| Avalonia UI | Avalonia (+ コミュニティー) | デスクトップ端末 | 統一 (Skia) | C#, F#, VB.NET |

[^main-target]: 公式が明示しているわけではないが、モバイルとデスクトップのどちらかというと
